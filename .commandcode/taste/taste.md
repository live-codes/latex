# Taste

## Workflow
- Prefers to start a new feature with a minimal proof-of-concept before doing full/real implementation. Confidence: 0.7
- Prefers browser-based, fully client-side solutions that run with no server/backend. Confidence: 0.7
- Prefers alternative implementations/engines explored as separate side-by-side demos (adding a new one rather than replacing the existing approach) when a proof-of-concept is being evaluated. Confidence: 0.5
